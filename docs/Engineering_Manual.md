### Resumen
- Carcasa: 156×162.4×148 mm (152 mm con patas).
- UM790 Pro + ESP32 + RC522 + OLED + HUB USB + Noctua NF-A12x15.
- Paneles NFC intercambiables con fijación magnética.
- Comunicación JSON por USB Serie.
- Software modular en Python y firmware ESP32.
